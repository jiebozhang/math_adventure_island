# 数学冒险岛 · 安卓端迁移设计文档

> 版本：v1.0 · 日期：2026-09-04
> 源项目：PyQt5 桌面版《数学冒险岛》v14 + v15 数据层 + v15 视图层
> 目标平台：Android 8.0+（minSdkVersion 26，targetSdkVersion 34）

---

## 一、功能规划（桌面 → 安卓）

源项目共四大模块：关卡冒险、数学题目、计分奖励、进度存档。下表明确每条功能在安卓端是 **保留 / 简化 / 新增**。

### 1.1 关卡冒险

| 桌面功能 | 安卓端 | 处理 | 关键说明 |
|---|---|---|---|
| 60 个知识关卡（4 领域 × 人教版 12 册） | 同 | **保留** | 数据原样加载，按"领域→册次→关卡"三层呈现 |
| 关卡前置依赖（`prerequisites`） | 同 | **保留** | 锁住未达条件关卡，地图上显示锁图标 |
| 七步闯关法（读题/条件/问题/方法/公式/检验/总结） | 同 | **保留** | 拆分到 7 个 Step 子页面，进度条驱动切换 |
| 当前航线进度（关卡 → 关卡连线） | 简化为横向滑动时间线 | **简化** | 桌面用画布箭头，移动端改 swipeable timeline |
| 思想印记展示（六大思想：数形结合/转化/方程/模型/统计/推理） | 同 | **保留** | 改为关卡卡顶端的标签徽章 |
| 关卡间"小衔接关"（3 个） | 同 | **保留** | 衔接关单独着色提示"两册桥梁" |
| 关卡旁笔记/草稿纸（DraftPaperWidget） | 简化为整页手写板 | **简化** | 桌面是浮窗；移动端改为可下拉抽屉 |
| 切换册次（年级/学期选择器） | 顶部下拉选择器 | **简化** | 桌面是 QComboBox，移动端改成 AppBar Dropdown |
| 离线 AI 出题（generate_questions_with_AI） | **新增** | **新增** | 安卓端加入"AI 陪我练"，需联网（智谱/豆包），家长侧开关 |
| 关卡语音讲解（TTS） | **新增** | **新增** | 每步可点喇叭朗读，移动端必备 |
| 跨设备继续闯关（扫码/口令） | **新增** | **新增** | 通过 Supabase 拉取云端进度，二维码快速迁移 |

### 1.2 数学题目

| 桌面功能 | 安卓端 | 处理 | 关键说明 |
|---|---|---|---|
| 113 内置题 + 68 自定义题 | 同 | **保留** | JSON 资产打进 APK，包大小预估 +300 KB |
| 题目标准化结构（story/text/answer/method_hint/hidden_traps/reference/image/image_desc） | 同 | **保留** | 数据模型原样 |
| 题目配图（小棒图/线段图/几何图形） | 缩放/平移/双指缩放 | **简化** | 桌面是 PyQt QLabel，移动端改为 ImageView + PinchZoomOverlay |
| 拼音标注（pinyin_enabled） | 同 | **保留** | 字号小一号即可，不改逻辑 |
| 语音输入答案（Google Speech） | 同 + 高频 | **保留** | 安卓原生 SpeechRecognizer 比桌面更稳 |
| AI 判题（llm_judge_enabled） | 同 | **保留** | 网关接入，家长侧默认关闭 |

| 草稿纸手写 | **新增** | **新增** | Canvas 手写识别（可选），轨迹直接保存 |
| 拍照搜题（家长辅助） | **新增** | **新增** | 限定每日 3 次，需家长解锁 |
| 错题本自动归集 | **新增** | **新增** | 答错题自动入库，错题本可重做 |

### 1.3 计分奖励

| 桌面功能 | 安卓端 | 处理 | 关键说明 |

| 周挑战任务 | **新增** | **新增** | 每周 5 个进阶题，奖励限定徽章 |

### 1.4 进度存档

| 桌面功能 | 安卓端 | 处理 | 关键说明 |
|---|---|---|---|
| 本地 JSON 存档（progress.json） | 同 | **保留** | Android 内部存储 `filesDir/progress.json` |
| 原子写（.tmp + os.replace + fsync） | 同 | **保留** | Kotlin `File.outputStream` + `flush()` + `renameTo` |
| 7 天 backup 滚动 | 同 | **保留** | `backup/progress_YYYYMMDD.json` |
| 损坏自动恢复（`_load_progress_with_recovery`） | 同 | **保留** | 启动时校验，失败则回退最近 backup |
| 家长锁（SHA-256 + 盐） | 升级为生物识别 | **简化+升级** | 安卓支持指纹/面部，盐值同源 |
| 云同步 Supabase（可选） | 同 | **保留** | `supabase_config.local.json` 改为运行时输入 |
| 多端同步冲突解决（last-write-wins） | **升级** | **新增** | 引入 `device_id` + `updated_at` 比对 |
| 自动云备份（每日） | **新增** | **新增** | WorkManager 每日触发 |
| 进度导出 PDF（家长周报） | **新增** | **新增** | 用 Android Print Framework 生成 |

### 3.2 页面导航结构

单 Activity + Compose Navigation，4 个一级 Tab + 9 个二级页：

```
MainActivity (NavHost)
├── Tab 1 冒险（NavGraph: home）
│   ├── HomeScreen              首页主菜单
│   ├── MapScreen               冒险地图
│   ├── TopicDetailScreen        单关详情（题目列表）
│   └── QuestScreen (×7 子页)    七步闯关 [step 1..7]
│       └── ResultScreen          闯关结算（Dialog 替代方案：BottomSheet）
├── Tab 2 图鉴（NavGraph: codex）
│   ├── CodexScreen              怪兽图鉴
│   └── WrongBookScreen          错题本
├── Tab 3 日记（NavGraph: diary）
│   ├── DiaryListScreen          日记列表
│   └── DiaryDetailScreen         单条日记
└── Tab 4 家长（NavGraph: parent）
    ├── ParentDashboardScreen     家长中心
    ├── ParentPinScreen           PIN 解锁
    ├── ParentSettingsScreen      学习设置
    └── ParentReportScreen        周报（PDF）
```

**导航规则：**
- 七步闯关：`step_N` → `step_N+1` 通过 QuestViewModel 的 `currentStep` 状态切换，物理上仍为一个 Composable
- 闯关中按返回键：弹"确认退出？已答进度会保存"
- 闯关结算 → 回地图：通过 `popBackStack("home", inclusive=false)`

### 3.3 本地数据存储方案

## 四、迁移要点（桌面 → 安卓）

### 4.1 交互差异

| 桌面行为 | 安卓行为 | 改造点 |
|---|---|---|
| 键盘输入数字 | 触屏数字键盘 + 语音输入 | 引入自定义 `NumberKeyboard` Composable；保留 SpeechRecognizer 入口 |
| 鼠标点击 + hover | 触屏单击 + 长按 | 所有 hover 效果改为 press / long-press；图标按钮加大命中区（≥48dp） |
| 窗口可拖拽 + 缩放 | 全屏沉浸式 / 强制竖屏 | 隐藏 ActionBar，全屏可切换但默认竖屏 |
| 键盘快捷键（Enter 提交、Esc 退出） | 滑动手势 + 系统返回键 | 监听 `BackHandler`，弹确认对话框 |
| 鼠标滚轮滚动 | 列表滚动 + 手势 | 用 `LazyColumn` + `verticalScroll` Modifier |
| 多窗口并行（草稿纸+题目） | 单屏分屏/抽屉 | 草稿纸改为可下拉 `BottomSheetDrawe`r，不与题目同屏 |
| 系统托盘 + 桌面快捷方式 | 桌面图标 Widget | 加 AppWidget 显示"今日任务 1/3" |
| 文件系统可访问 | 沙盒私有目录 | 进度 JSON 移到 `context.filesDir` |
| PyInstaller 单文件 exe | APK（assets） | 题目 JSON / 图片全部打进 `assets/`，避免运行时下载 |

### 4.2 屏幕适配

**断点策略：**

| 断点 | 宽度 | 布局 |
|---|---|---|
| Compact（手机竖屏） | < 600 dp | 单列（默认） |
| Medium（小平板/折叠屏） | 600~840 dp | 答题区 60% + 草稿 40% |
| Expanded（大平板） | ≥ 840 dp | 左右分屏（题目+草稿同屏） |

**字体/间距：**
- 字体缩放：尊重系统字号（sp 单位，不强制固定 dp）
- 最小可点击区：48×48 dp（Material Guideline）
- 安全区：顶部 StatusBar 24dp、底部 NavigationBar 24dp、刘海屏 `WindowInsetsCompat`

**横屏适配：**
- 主菜单/地图：横屏时改为 2 列网格

### 4.3 性能问题

| 桌面问题 | 安卓风险 | 应对 |
|---|---|---|
| 单文件 Python 加载快 | APK 启动加载 113 题 JSON | 启动只加载"当前年级 + 下一册"，约 30 题；其余按需懒加载 |
| PyQt 同步渲染 | Compose 重组开销 | 用 `derivedStateOf` 缓存计算；`remember` 避免重复解析 |
| 7 步连续 7 个 Frame | 7 个 Composable 重建 | 用 `NavHost` + `LaunchedEffect` 缓存每步状态；不在切步时重建 ViewModel |
| 60 关卡地图 1 次性绘制 | 滚动卡顿 | `LazyColumn` + `key()`；只渲染可视区 |
| 草稿纸手写轨迹 | Canvas 重绘开销 | 用 `Path` 而非 `drawLine` 循环；抬起时再压缩为 PNG |
| 经验条动画 | 渲染掉帧 | 用 `animate*AsState` 缓动；不要每帧 setValue |
| 语音识别常驻耗电 | 后台耗电 | 仅在答题页 onResume 时启动，onPause 立即释放 |
| TTS 朗读 | 阻塞 UI | 用 `TextToSpeech.synthesizeToFile` 异步生成 + MediaPlayer 播放 |
| LLM 联网请求 | 网络抖动 + 家长担忧 | 加 30s 超时；离线时隐藏入口；网络异常 Toast 提示 |
| 内存峰值（桌面 200MB+） | 手机 OOM 风险 | 题目图片转 WebP + 缩略图；列表用 ViewModel 范围持有 |
| APK 体积 | 移动端下载敏感 | 题库 JSON gzip 后 -60%；图片全部 WebP；总包预估 < 30 MB |

### 4.4 工程要点

1. **数据迁移**：桌面 progress.json → 安卓可直接解析（schema 完全兼容）；首次启动检测到桌面版 backup 文件，提示"是否导入旧进度"
2. **家长 PIN 兼容**：沿用 SHA-256 + 同一盐值（`math_adventure_island_parent_lock_v10`），用户无需重新设置
3. **题库兼容**：113 内置题 JSON 直接复用 `math_adventure_island_v15_data.py` 导出物
4. **依赖替换**：PyQt5 → Jetpack Compose；requests → Retrofit；sqlite3 → Room；QSettings → DataStore
5. **测试策略**：保留桌面版作为"事实基准"，安卓端先用相同数据回放，验证 7 步流程输出一致
6. **隐私合规**：语音/AI 调用需家长侧开关；不上传儿童语音原文；Supabase 同步前需家长 PIN
7. **家长 PIN 安全**：桌面端 SHA-256 单纯哈希；安卓端建议升级为 EncryptedSharedPreferences（AES-256）+ 设备绑定
